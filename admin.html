Your token is saved only in this browser. Don't use this page on a shared computer, or click "Sign out" when you're done.

How to make the token

  1. On github.com go to Settings, then Developer settings, then Personal access tokens, then Fine-grained tokens, and click Generate new token.
  2. Repository access: Only select repositories, and pick this site's repo.
  3. Permissions: Contents: Read and write and Actions: Read-only. Leave everything else as it is.
  4. Pick an expiry date, generate the token, and paste it above.
